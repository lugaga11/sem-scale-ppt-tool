# SEM 图片工具

在一个 PySide6 窗口中完成 **截图查找原图 → 标定 / 测量 → 导出 PPTX 或 SVG**。
这是原“搜图”和“SEM 标尺 PPT/SVG 工具”的合并版本，主项目位于 `D:\Codex\python\sem-github`。

## 启动

使用现有 `my_base` 环境，无需重新安装依赖：

```powershell
Set-Location 'D:\Codex\python\sem-github'
& 'D:\Program Files\Anaconda3\envs\my_base\python.exe' main.py
```

也可运行 `python -m sem_tool`，或双击打包后的 `dist\SEMTool.exe`。
启动时可以传入图片或文件夹，例如 `python main.py 'D:\SEM 图片'`，直接加入标注队列。
默认打开首个“标注与导出”页，可直接添加图片；需要搜图时再切换到“查找原图”。

新环境使用 Python 3.10 或以上：

```text
python -m pip install .
sem-tool
```

依赖统一在 `pyproject.toml` 中：PySide6、Pillow、NumPy、OpenCV、python-pptx。
新环境使用 `opencv-python-headless`，界面统一交给 PySide6；已有环境中的 `opencv-python` 也能运行，无需同时安装两种 OpenCV 包。

## 从截图到标注

1. 在“查找原图”页选择图库，点击“更新索引”。图库会递归扫描，目录会自动记住。
2. 选择截图、拖入截图，或使用“粘贴截图”/ `Ctrl+V`。
3. 点击“搜索”，查看候选原图、置信度和匹配信息。
4. 点击需要的那张结果旁的“加入列表”。成功后按钮变为绿色“已加入”，大小保持不变；从队列删除后可重新添加。添加后留在搜索页，方便继续搜图。
5. 切换到“标注与导出”，点击图片的测量按钮。有 SEM TIFF 像素标定时点击“编辑”；无标定时橙色按钮显示“手动标定”：沿已知长度画线，输入 `1um` 或 `500nm` 等长度。应用标定后返回列表，需要测量时再点击“编辑”。
6. 在预览里添加膜厚或任意测距，点击“应用标注”。回到“标注与导出”页，选择格式和保存路径后生成。

传入标注的是**原始文件路径**，不是缩略图或查询截图。重复加入同一路径会选中已有队列项，保留它的勾选、标定和测量；不同目录的同名文件分别保留。两个页面可以来回切换，队列状态不会丢失。

支持 `.tif`、`.tiff`、`.png`、`.jpg`、`.jpeg`、`.bmp`、`.webp`。搜索只在指定的本地图库进行，不上传图片。

## 标注与导出

- 界面采用蓝白配色、紧凑的顶部标签和双栏布局：文件队列占满左侧，右侧为标尺和输出设置；“生成”按钮固定在右侧底部，小窗口中滚动参数时也可直接操作。
- 队列显示缩略图和所在目录，双击文件可打开原图，点击测量按钮进入编辑器。鼠标在缩略图上停留片刻，会显示完整比例的放大图、尺寸、格式、文件大小、标定信息、修改时间和路径；移开、滚动或切换页面时自动收起。缩略图与悬停放大图按需加载，使用与测量编辑器一致的显示映射。
- 队列保持“生成 / 文件 / 测量”三列和单选，支持拖动排序；双击“文件”列打开原图，生成勾选框只切换勾选状态。
- 直接将图片或文件夹拖入队列添加；“全选 / 取消全选”和排序位于队列上方，控制生成勾选。添加文件、添加文件夹、删除和清空位于右上角“···”菜单，测量和标定操作保留在图片右键菜单中。
- “生成”控制是否导出；新图片默认生成、不带测量。只有应用到队列的标注才会导出。
- 标注和标定窗口以图片为主，可使用原生最大化按钮扩大画布。标注工具、删除、清空和“适应窗口”集中在顶部；标定窗口底部横向排列实际长度、像素长度与计算结果。右上角“?” 提供操作说明，底部右侧应用或取消。
- “膜厚”首次点击时才运行自动界面识别，作为可拖动修正的建议。生成文件时不会擅自添加膜厚。
- “测距”允许任意两点、多条线段；拖动端点修改，拖动线段整体移动，`Shift` 锁定八个方向。
- `Ctrl+滚轮` 缩放，中键拖动平移；`Ctrl+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 重做、`Delete` 删除、`Esc` 取消绘制。“取消”不保存当前预览改动。
- 队列右键可手动标定、恢复元数据标定、清除测量和删除图片。手动标定优先于元数据，并同时用于标尺、膜厚和测距。
- 打开“自动长度”开关后，可直接选择短 / 中 / 长，按视野动态选择 `1/2/5 × 10ⁿ` 系列；关闭后可输入固定长度，必须为有限正数，且不能超过图像视野。
- 可设置标尺角落位置、横向/纵向内缩、线宽、颜色、字体、加粗和页面边距；颜色可填 `white`、`black`、`red`、`green`、`blue`、`yellow` 或 `#RRGGBB`，色块显示的就是导出的颜色，无法识别时显示“?”并在生成前提示；字体、内缩和页边距位于“更多设置”中，切换自动/固定长度时显示对应输入。启动默认值在 `sem_tool/annotation/core.py` 的 `DEFAULTS` 中。
- “运行日志”是第三个独立标签页，不占用标注页空间；切换页面不影响记录，导出失败时自动切到日志页，每次开始导出时清空上次日志。

PPTX 使用 16:9 页面，每张图片一页；标尺和测量是可编辑的原生线条和文本对象。
SVG 贴合图片比例，每张图片单独保存，例如 `结果_01_原图名.svg`；一份无损 PNG 嵌入数据加矢量线条/文字，适合导入 Illustrator。SVG 线段使用直角端点，不添加 marker 或额外三角形。

16 位灰度 TIFF 的搜索、缩略图和测量预览共用 8 位显示映射；导出保留原始 16 位灰度 PNG，不修改源图片。
测量和手动标定仍保存在当前会话，关闭程序后不保留；导出文件会保留已经应用的标注。

## 索引与本地数据

为了直接沿用旧搜索工具的数据，合并版本继续使用：

```text
%LOCALAPPDATA%\ImageOriginFinder\
├── index.sqlite
├── settings.json
└── clipboard\
```

“更新索引”增量处理新增、修改、删除及上次失败的文件；“重建索引”重新扫描当前图库。
搜索页保留常用的“更新索引”；打开索引目录、重建、清理失效、压缩和清空操作统一放在“索引管理”菜单中。
查找原图页保留上方截图 / 图库输入和下方结果列表；细进度条仅在任务运行时出现，百分比与剩余时间显示在独立状态文字中。
“清空索引”和“清理失效”只删除数据库记录，“压缩索引库”回收数据库空间。
`clipboard\` 保存粘贴的截图，超过 7 天的会在下次粘贴时自动清理。
图库变化时会提示更新；低置信度匹配需要查看原图确认。

测试或便携数据目录可通过环境变量 `SEM_TOOL_DATA_DIR` 指定。程序不要求源码或 exe 所在目录可写。

## 项目结构

```text
sem-github/
├── main.py                    # 统一启动入口
├── pyproject.toml             # 安装、依赖、开发工具配置
├── SEMTool.spec               # 唯一 PyInstaller 配置
├── README.md
├── AGENTS.md                  # 简短协作约定
├── docs/
│   ├── development.md         # 开发与验证
│   └── migration.md           # 模块迁移与旧数据说明
├── sem_tool/
│   ├── __init__.py
│   ├── __main__.py
│   ├── app.py                 # 主窗口与搜索→标注连接
│   ├── theme.py               # 紧凑浅色主题与控件绘制
│   ├── widgets.py             # 分段选择、开关与路径输入框
│   ├── image_widgets.py       # Qt 显示映射与等比图片组件
│   ├── assets/                # 导航、操作与输入控件的矢量图标
│   ├── files.py               # 图片格式、路径、去重、文件打开
│   ├── imaging.py             # 统一显示映射与无损图片转换
│   ├── settings.py            # 用户数据与设置
│   ├── search/
│   │   ├── engine.py          # ORB / RANSAC 匹配
│   │   ├── index.py           # SQLite 增量索引
│   │   ├── worker.py          # 后台搜索/索引与进度限流
│   │   └── ui.py              # 搜索面板、结果操作
│   └── annotation/
│       ├── core.py            # 标定、测量计算、PPTX / SVG 生成
│       ├── preview.py         # 标定和测量编辑窗口
│       ├── hover.py           # 队列缩略图的悬停放大浮层
│       ├── queue.py           # 队列与输入控件
│       ├── worker.py          # 后台导出
│       └── ui.py              # 标注队列与导出参数面板
├── scripts/verify_sample.py    # 可选本地搜索样例验证
└── tests/                     # 自动化回归与跨模块流程测试
```

`sample/`、`artifacts/`、`build/`、`dist/` 为忽略的本地数据或生成产物，不进入安装包。
构建和验证命令见 [开发说明](docs/development.md)，旧文件映射见 [迁移说明](docs/migration.md)。
