# SEM 标尺 PPT/SVG 工具

用 PySide6 图形界面把 SEM 图片批量生成 PowerPoint 或 SVG，并自动添加可编辑长度标尺。


## 使用方式

在 VSCode 中打开并调试：

```text
sem_scale_ppt_gui.py
```

如需修改启动默认值，编辑 `sem_scale_ppt.py` 顶部的 `DEFAULTS` 配置块。

界面功能：

- 左侧是紧凑文件队列表格，右侧是输出和标尺设置。
- 可将 SEM 图片或文件夹直接拖入文件队列。
- 双击队列文件可打开原始图片。
- 可添加文件、添加文件夹、拖动排序、全选生成、取消全选、删除选中、自然排序、清空队列。
- 可在队列中分别勾选每张图片是否生成。
- 来自不同文件夹的同名文件会作为不同队列项保留。
- 文件队列行选择为单选，不支持按住 `Ctrl` 或 `Shift` 多选。
- 导入图片时会预检像素标定；缺少标定的文件显示警告图标，行内 `编辑` 按钮显示为红色，队列统计显示缺标定数量，生成前会再次检查。
- 每行的 `测量` 列包含一个编辑按钮；无标注时显示 `编辑`，有标注时显示 `膜厚`、`测距 2` 或 `膜厚+测距 2`，生成时会自动导出这些标注。
- 点击测量按钮会打开图片预览，顶部用 `膜厚` 和 `测距` 作为添加/编辑工具。
- 点击 `膜厚` 会在预览中新增或选中一条膜厚标注，自动识别只用于给出初始红/蓝界面线；可拖动红/蓝线校准厚度，也可拖动中间竖线调整标注位置。
- 点击 `测距` 后可在图片上拖拽任意两点添加距离标注，一张图可添加多条；选中已有标注后可拖动端点调整，按住 `Shift` 可锁定到 0/45/90 度等八个方向。
- 预览中 `删除选中`、`清空标注`、`重置选中` 对膜厚和测距使用同一套操作；`应用` 才写回队列，`取消` 会丢弃本次预览改动。
- 队列右键菜单提供 `手动标定…`、`恢复元数据标定`、清除选中测量标注和删除选中。
- 可在输出格式中选择 `PPTX` 或 `SVG`。
- `生成 PPTX` / `生成 SVG` 会保存到指定输出路径。
- 自动标尺长度支持短/中/长三档，也可固定为 `1um`、`500nm` 这类值。
- 导入文件夹时测量默认不勾选，可手动选择断面图添加竖向厚度箭头，或在颗粒、孔洞等任意位置添加测距箭头。
- 可调整标尺位置、横向/纵向内缩、线宽、颜色、字体大小、是否加粗和页面边距。

右下角标尺时，横向内缩越大越靠左，纵向内缩越大越靠上。

生成 PPTX 时，标尺、测膜厚和测距标注都是 PowerPoint 原生线条/箭头属性/文本框；生成 SVG 时，页面会贴合图片比例，不保留 16:9 背景，图片保持栅格，标尺线、测量纯线段和文字用矢量对象绘制，方便拖入 Illustrator 后继续编辑。

导出 SVG 时，工具会为每张图片生成独立 SVG；即使只导出一张图片，命名也会带上原图名，格式为 `输出名_01_原图名.svg`、`输出名_02_原图名.svg`。
图片会先无损转换为临时 PNG，再以一份 base64 数据嵌入 SVG；生成完成后临时 PNG 会自动删除。

截面厚度识别只在预览中点击 `膜厚` 或重置膜厚标注时用于给出初始界面线，适合界面较清楚、层状结构明显的截面图。算法会排除底部信息栏，在多个横向窗口中寻找上界面和下界面的亮脊峰值；生成时只使用你在预览中应用后的测量标注。测量标注只保存在当前队列会话内，核心导出统一按 `MeasurementOverride(kind, x1, y1, x2, y2)` 换算长度。

## 依赖

安装运行依赖：

```text
python -m pip install PySide6 pillow python-pptx
```

其中 `python-pptx` 用于 PPTX 导出，`PySide6` 用于图形界面，`pillow` 用于读取图片和 SEM TIFF 元数据。SVG 导出不需要额外依赖。

## 元数据和手动标定

工具会尽量读取 SEM TIFF 元数据：

- `PixelSize=...` 按 `nm/pixel` 处理。
- 支持 `Image Pixel Size = ... nm` 和 `Pixel Size = ... nm`。

如果图片没有标定元数据，或需要覆盖元数据值：

1. 在队列中选中并右键图片，点击 `手动标定…`。
2. 沿图中一段已知长度拖出标定线；按住 `Shift` 可锁定到水平、垂直或 45 度方向。
3. 输入实际长度，例如 `1um` 或 `500nm`。
4. 确认计算出的 `nm/px` 后点击 `应用标定`。

手动标定优先于图片元数据，同时用于横向标尺、膜厚和测距；右键选择 `恢复元数据标定` 可取消覆盖。如果原图本身没有元数据，取消手动标定后会重新显示缺标定警告。
